# Regusto: publicar o site EXATAMENTE como o protótipo

O arquivo `index.html` deste repositório é o site APROVADO pelo cliente. O visual, o layout, as cores, as fontes, os textos e as animações devem ficar EXATAMENTE como estão.

## Regras
- NÃO redesenhar, NÃO trocar cores, fontes, espaçamentos, ordem das seções nem animações.
- NÃO adicionar seções, efeitos, bibliotecas ou frameworks novos. Continua sendo HTML, CSS e JS puros num único arquivo.
- NÃO inventar itens nem preços.
- Qualquer mudança fora das tarefas abaixo: pergunte antes.

## Tarefas (só estas)
1. Abrir https://regusto.com.br, conferir o cardápio completo e completar o array `MENU` no `index.html` com os itens e preços que faltam (bebidas, refrigerantes, sobremesas etc.), usando exatamente o mesmo formato dos itens existentes. Criar novas categorias no `MENU` só se existirem no site atual.
2. Adicionar no `<head>`: favicon simples (emoji 🍽️ via SVG inline), meta tags Open Graph (título, descrição) e `theme-color` #111111.
3. Testar no celular (largura 375px) e no desktop: abrir item, escolher misturas, adicionar à sacola, remover, alternar entrega/retirada e enviar pedido para o WhatsApp. Corrigir apenas bugs, sem mexer no visual.
4. Preparar para deploy estático na Vercel (sem build) e fazer o deploy.

## Ao terminar
Liste o que foi alterado, linha a linha, e confirme que o visual não mudou.
